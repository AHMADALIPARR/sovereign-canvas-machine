# ADR 0005 — Two implementations, no borrowed authority

The Perl checker and the C runtime in compcert/scm_rt.c recompute the
same invariant. A proposal is accepted only when they agree. That C is
compiled with gcc and is not a CompCert certificate. The Lean kernel and
the Prolog theory are the same decision written for those systems; this
bootstrap does not claim they were executed. AMPL states the permutation
bound; the executed bound is the BFS in the Perl optimizer.
