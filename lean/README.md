# Lean kernel

`Kernel.lean` defines the Artin action and proves the braid relation and inverse cancellation with kernel-checked `decide` (previously `native_decide`; the statements are unchanged, the evidence is stronger because it no longer trusts native code evaluation). It typechecks with Lean 4.12 (`~/.elan/bin/lean` on the build machine; the toolchain is not on the default PATH). `tests/suite.pl` typechecks it whenever a Lean binary is found, and skips the check with a note when none is installed. The running proof remains the agreement of the Perl checker and `compcert/scm_rt.c`; the Lean kernel is the independent formal statement of the same action.

## Mathlib layer

The Mathlib layer is a Lake project in `lean/mathlib/`, pinned to Lean v4.9.0 and Mathlib v4.9.0 (`lean-toolchain`, `lake-manifest.json`), with the prebuilt Mathlib cache in its `.lake/` (not tracked in git). `MathlibLayer.lean` imports all of Mathlib and carries the layer's wiring proofs; `lake build` in `lean/mathlib/` compiles it against the pinned dependency. The framework development for this layer — matrix interpretation, permutation representation, exponent sum, and the explicit axiom for Artin faithfulness, which is not provable from the kernel's definitions alone — is not yet written. The kernel's `decide` proofs are the verified formal content, and the Perl matrix/exponent-sum cross-check (`SCM::Braid::exact_braid_equal`) is the executed counterpart of the matrix interpretation.
